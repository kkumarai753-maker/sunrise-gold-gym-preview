# Sunrise Gold Gym

Responsive gym website preview for Sunrise Gold Gym, Nagpur.

## Features

- Complete responsive one-page website
- Working navigation and mobile menu
- Program, membership, club gallery and enquiry sections
- Accessible concept-film modal and enquiry validation
- No build step required; deploy `index.html` as a static site

The enquiry form currently stores preview submissions only in the visitor's browser. Connect the final CRM or WhatsApp endpoint before public launch.
